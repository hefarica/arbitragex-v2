# Grafana dashboards

Four dashboards are provisioned at Grafana boot via the volume mount declared
in `docker/compose.dev.yml` / `compose.prod.yml`. The provider config
`dashboards.yml` loads every `*.json` file from this directory.

Dashboards:

- **platform-overview.json** — `arbx-platform-overview`
  Services-up count, kill-switch state, opportunity rate, execution rate,
  HTTP throughput + 5xx + p95 latency per service.
- **detection-pipeline.json** — `arbx-detection`
  Mempool throughput (pending → decoded → opportunity funnel), WS reconnects,
  undecoded reasons, dropped reasons, per-chain × per-strategy opportunity rate.
- **execution-pipeline.json** — `arbx-execution`
  Selector accept/reject, reject-reason breakdown, simulation pass/fail per
  simulator, executions by relay × status, selector processing latency p50/p95/p99.
- **recon-risk.json** — `arbx-recon-risk`
  Blacklist hits, token-safety cache hit ratio, circuit-breaker trips and state,
  consumer lag, selector invalid-message rate.

## Contract

Every panel `expr` references an `arbx_*` metric that actually exists in
`backend/shared-rs/src/metrics.rs` or `shared-ts/src/metrics/index.ts`. No
synthesized panels. The enforcement lives in
`automation/tools/verify-dashboard-metrics.sh` and runs in CI via
`.github/workflows/no-hardcode.yml`.

Histogram suffixes (`_bucket`, `_sum`, `_count`) are auto-generated by
Prometheus — the script strips them before lookup.

## Editing

- Dashboards can be edited live in the Grafana UI (`editable: true`). When you
  save changes that should persist across restarts, export JSON and commit the
  file back here.
- Before committing an edit, run `bash automation/tools/verify-dashboard-metrics.sh`
  locally. CI enforces the same check.

## What appears empty until data exists

Without a real RPC, `arbx_searcher_pending_total`, `arbx_opportunity_total`,
`arbx_execution_total` all stay at zero. Panels render empty — that is honest,
not broken. `arbx_service_up` and `arbx_killswitch_enabled` populate
immediately, so the platform-overview header tiles give you a live signal
from the first boot.

Concrete strategy families NOT in the 264 catalog (which already covers same-chain spot arb 36, tx-triggered 31, parity/redemption 31, cross-chain 30, derivatives 30, lending/liquidations 25, intents/auctions 20, NFT 18, AMM-curve 17, CEX-DEX 14, prediction markets 12). Derivations with topology and math:

1. **MEV-Share / OFA conditional-backrun capture (programmable-privacy surface)** — Topology: [user tx with hint] -> [our backrun bundle] submitted to MEV-Share; user gets rebate, we keep residual. Math: for a hint-observable swap of size V in pool with reserves (x,y), optimal backrun size x* solves max_x f(x; post-user state) - gas - bid; submit iff bid share s*π <= π where s = platform share + user refund (MEV-Share defaults ~10% platform of *our* refund; calibrate per auction). Winner's-curse-adjusted: E[profit] = P(win|s)·π·(1-s) with P(win|s) estimated from historical auctions ([ML bidding, eprint 2023/1281](https://eprint.iacr.org/2023/1281); [searching on MEV-Share](https://writings.flashbots.net/searching-on-mev-share)). Detection operator: none of the 31 needed beyond a conditional simulator keyed on hint events (hash, log hints, gas) — a new `hint_conditional_simulator` detector class.

2. **JIT liquidity provision (V3/V4, mint->swap->burn)** — Topology: [our mint of narrow range [pa,pb] around current tick] -> [victim/large swap] -> [our burn], all in one block, one bundle. Math: fee capture F = fee_tier · V_swap · L_ours/(L_ours + L_pool) for range covering the price path; cost = gas(3 txs) + inventory risk if swap path exits range (inventory delta Δ = f(V, depth)). Opportunity iff F > 2·gas + tail-risk term; on V4 must pre-check hook flags (beforeSwap/afterSwap and burn-delay hooks break the pattern) ([eprint 2023/973](https://eprint.iacr.org/2023/973), [Uniswap Labs](https://blog.uniswap.org/jit-liquidity), [v4-hook defense analysis](https://academy.exmon.pro/future-of-liquidity-uniswap-v4-hooks-vs-jit-mev-attacks)). Note: repo operator op_28 "Jit Liquidation" is liquidation decay — this is a distinct LP surface.

3. **Dutch-auction liquidation timing under Aave-V4-style dynamic rewards** — Topology: observe health factor HF_i < 1 at block t; reward r(t) = r_0 + κ·t escalates; competing liquidators arrive as Poisson(λ). Optimal strike time t* solves ∂r/∂t = λ·(r(t*) - c_gas)·P(capture at t*) — i.e., fire when marginal reward growth equals hazard-weighted expected loss to competition. With SVR/builder-integrated liquidations, value splits with the builder: maximize (1-s)·r(t) - c. ([Aave V4 liquidations](https://aave.com/blog/aave-v4-liquidations), [Euler forum model](https://forum.euler.finance/t/mev-in-euler-dutch-auctions/1012).)

4. **Oracle-staleness latency arbitrage (fresh AMM vs lagging consumer)** — Topology: 2 venues for the same asset: AMM (instant state) vs protocol consuming a Chainlink feed with heartbeat H and deviation threshold d (or a short TWAP). After a spot move of magnitude > d, for a window w <= H the consumer's price is stale: execute against the stale-priced venue and hedge on the fresh venue. Math: edge = |p_spot(t) - p_oracle(t_last)| - gas - slippage s(x); opportunity iff edge > 0 AND expected window remaining E[H - (t - t_last)] > inclusion latency. Detection requires per-feed heartbeat/deviation tables as data bindings ([OWASP SC03 2026](https://github.com/OWASP/www-project-smart-contract-top-10/blob/main/2026/en/src/SC03-price-oracle-manipulation.md), [Cyfrin staleness guidance](https://medium.com/cyfrin/chainlink-oracle-defi-attacks-93b6cb6541bf)). This is simultaneously the defense checklist — the same monitor protects against being the stale venue's counterparty in toxic flow.

5. **Cross-chain inventory-skip arbitrage (vertical-integration topology)** — Topology: maintain balances B_A, B_B on chains A,B; when |p_A - p_B| > fees_A + fees_B + rebalancing amortized cost ρ, sell on the high chain, buy on the low chain as two independent same-block executions; rebalance lazily via bridge/CEX when inventory ratio breaches band. Math: classic two-location newsvendor: edge activation threshold θ = gas + ρ(B) where ρ amortizes bridge cost over expected rebalancing volume; sizing by Kelly on correlated leg fills (fill risk per leg ~ inclusion prob per chain). This replaces the Excel's NONATOMIC_BRIDGE_REQUIRED topology with NONATOMIC_INVENTORY + parallel atomic legs — empirically the winning class ([ACM cross-chain arb](https://dl.acm.org/doi/10.1145/3771566), [CoW](https://cow.fi/learn/cross-chain-mev-how-bots-extract-value-when-you-move-between-chains)).

6. **Uniswap V4 hook-adjusted pool arbitrage** — Topology: pools whose swap curve is modified by hooks (dynamic fees f(state), beforeSwap/afterSwap deltas, custom curves). Effective output Q(x) = g_hook(q(x), f(state)); opportunity iff closed-route Π_R(x) = Q_R(x) - x - C_R(x) > 0 evaluated *through simulation including hook state slots* (hook addresses and their storage must be part of Data_Bindings — a new binding class). Requires per-pool hook registry ingestion + safety screen (only audited hooks; pool-key spoofing and access-control risks per [CertiK](https://www.certik.com/blog/uniswap-v4-hooks-security-considerations), [Hacken](https://hacken.io/discover/auditing-uniswap-v4-hooks/)).

7. **RL-tuned (size, bid) policy for repeatable cartridges** — Topology: wrap any high-frequency cartridge (DEX-DEX, backruns) in a PPO policy (op_31 exists — apply it at the *decision* layer, not as an operator on numbers): state = (spread, volatility, reserve depth, competitor-count proxy from auction outcomes, time-in-block), action = (trade size x, bid b), reward = realized net profit. Cites: [RL MEV on Polygon](https://arxiv.org/html/2510.14642v1), [ML bidding](https://eprint.iacr.org/2023/1281). The repo's PAPER_SHADOW ledger is exactly the replay buffer this needs (currently blocked by null-economics emission — fix the emission, then this becomes trainable).

8. **Builder/ePBS-era inclusion arbitrage (forward-looking, ~Q3 2026)** — Post-EIP-7732+FOCIL, proposer commitments and inclusion lists create a *predictable* inclusion window: strategies keyed to list-commitment contents (observe FOCIL pre-confirmations, trade the remainder of the slot) — a new DEX_STATE sub-family whose trigger is consensus-layer, not mempool ([EIP-7732](https://eips.ethereum.org/EIPS/eip-7732), [Sigma Prime](https://sigmaprime.io/blog/glamsterdam-eip-preferences/), [Flashbots Glamsterdam MEV view](https://collective.flashbots.net/t/an-mev-perspective-on-glamsterdam/5116)).

9. **Blob/L2 fee-market arbitrage** — EIP-4844 blob base fee decays/increases per block with excess data; L2 sequencer fee divergence creates route-the-same-trade-cheaper opportunities across L2s and timing arbitrage (delay vs accelerate execution based on blob-basefee EMA). Math: choose (chain_i, delay δ) = argmin E[c_i(gas_t+δ, blob_t+δ)] subject to edge-decay hazard on the arb itself. New surface: not in catalog (its CEX-DEX family covers venue arb but not fee-market state).

10. **TEE/sealed-bid participation surface** — as sealed-bid OFAs on confidential compute mature ([ACM 2025](https://dl.acm.org/doi/10.1145/3733815.3764043)), a cartridge class "bid inside TEE auction" emerges where strategy = bid function only (no latency edge), rewarding pure valuation accuracy — structurally different from all 264 (which assume open competition).

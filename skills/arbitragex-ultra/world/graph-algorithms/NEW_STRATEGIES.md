# New strategies not in our 264 catalog

Five-plus concrete new strategy types not in the 264 catalog (with topology + math), all read-only/shadow-compatible:

1. SPLIT-ROUTE CLOSED CYCLE (R_SPLIT_CYCLE). Topology: HolonomicLoopResolution where each LEG is a bundle of parallel pools for the same pair. Math: allocate x across parallel pools per leg so active pools equalize marginal price: maximize sum_j o_j(q_j) s.t. sum q_j = x per leg; solve by bisection on S(lambda)=sum_j mp_j^{-1}(lambda)=x (Xi-Moallemi, machine-precision); compose legs multiplicatively Q_R(x)=prod of split-leg outputs; opportunity iff max_x [Q_R(x)-x-C_R(x)]>0. Detector extends R_CLOSED_CYCLE with a per-leg split dimension. Expected gain: recovers the 2+ bps that single-path sizing loses.

2. EXACT-k MOST-NEGATIVE-CYCLE LADDER (R_KMNC_LADDER). Topology: k-indexed family of HolonomicLoopResolution, k=2..5 (per RICH, >5 hops <2% of cycles). Math: log weights w(u,v)=-ln((1-fee)r(u,v)); for each k run color-coding: omega >= log(1-P)/log(1-k!/k^k) instances of O(2^k|V||E|) DP dp[v][S]=min path weight with color set S; bitwise color-set encoding; color-guided graph reduction first. Emits k ranked cycles (not just first-found) with weight -> expected Topological Yield exp(-|w|)-1. Replaces bounded DFS entirely; adds hop-exact "layered strategies" the Excel's Min_Legs/Max_Legs model cannot express precisely.

3. OPEN NEGATIVE s-t PATH WITH INVENTORY REBALANCE (R_OPEN_PATH / line-graph MMBF). Topology: DiracImpulseOnly-shaped OPEN path (not closed) - enter token s, exit token t, profit realized because the negative path weight beats the external s/t price ratio or via pre-positioned inventory. Math: line graph L(G); super-source linked to s's edges; modified Moore-Bellman-Ford with vertex-simple constraint yields negative s-t paths for ALL t in one pass per s (N^2 paths total); then per path bisection on concave output; hedge the residual t-denominated inventory via the CEX-DEX or futures surface (family C_CEXDEX / D_BASIS). Evidence: 23,868 paths>$1K vs 19 cycle-only on the same data - a >1000x expansion of the candidate set.

4. AGGREGATE-CFMM TIER-AND-VENUE WATERFILL (CF_AGG_WATERFILL). Topology: OrthogonalEquilibrium across all Uniswap V3 fee tiers + V2 + Curve for one pair, each V3 pool collapsed to ONE concave output function over all ticks ("aggregate CFMM", Diamandis). Math: routing convex program or marginal-price vector pi in R^N with price-response functions; bisection + damped Newton; handles levered curves where CVXPY fails; up to 200x faster than conic solvers, scales to 1,000 curves. Opportunity = post-trade circularity violation: prod of marginal prices around loop > 1 (equivalently exists pi with p_marg(i,j) != pi_i/pi_j). Covers the Excel family "Arbitrajes segun la curva del AMM" (17 strategies) with an exact optimizer instead of per-curve heuristics.

5. STALENESS-DECAYED RANKING + EVENT-TRIGGERED RECHECK (E_STALE_RANK). Topology: meta-detector over ALL emitted candidates. Math: score(t) = Pi_R(x) * exp(-beta * staleness_blocks) - lambda_adv * P_sandwich(route), with beta calibrated from the Columbia measurement (1.29-1.78 bps/block FVO/G-FVO); staleness_blocks computed per-route as the MAX block-age of any edge on the route (or freshness-weighted: sum over edges of age-weighted reserve uncertainty); maintain a cycle-edge inverted index so a Sync event on pool p re-validates ONLY cycles containing p in O(#affected cycles) instead of full rescan - turning our purge/batching problems into an event-driven advantage. P_sandwich estimated from pool's historical sandwich incidence (public-flow routers show it, CoW-like flow doesn't).

6. REPATRIATION-OPTIMAL CYCLE EXIT (R_REPATRIATE). Topology: same cycle discovered once, but exit token chosen among all cycle vertices. Math (Bancor MPO appendix): for a solved cycle, compute profit denominated in EACH token on the cycle under the post-trade price vector pi; choose exit argmax_t Pi_t/pi_t - conversion cost; exploits the fact that the same arbitrage is worth different amounts depending on extraction token - a free EV bump on every existing R_CLOSED_CYCLE hit.

7. BACKRUN-OF-SYNC OPPORTUNITY SURFACE (E_BACKRUN_SYNC). Topology: event-triggered 2-hop mini-cycle. Math: on a Sync/Swap event that moves pool (a,b)'s marginal price beyond the no-fee-band of any OTHER pool for (a,b) or a 2-hop alternative (a,c),(c,b), the post-event stationary state violates marginal equalization; EV = Pi * P(top-of-block | bid) - bid per the OFA auction literature (MEV-Share); submit via private routing to avoid the sandwich/adverse-selection exposure that the Columbia audit attributes to public flow. This is the missing "competition-aware" wrapper around every existing strategy.

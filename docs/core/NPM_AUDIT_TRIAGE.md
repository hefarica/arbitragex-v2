| [GHSA-qx2v-qp2m-jg93](https://github.com/advisories/GHSA-qx2v-qp2m-jg93) / CVE-2026-41305 | `postcss` | 8.4.31 (transitive via `next`) | Moderate | Add `"overrides": { "postcss": ">=8.5.14" }` to root `package.json` | (b) `overrides` pin for transitive dependency | `next@15.5.18` (like all 15.x) still bundles `postcss@8.4.31` in its own `dependencies`. Since this is a transitive dep that `next` pins internally, a direct bump of `next` alone does not resolve the postcss vuln. The npm workspace-level `overrides` field forces all workspace packages to resolve `postcss` to `>=8.5.14` (latest: `8.5.14`). This is the correct and surgical fix for transitive dep pinning. |

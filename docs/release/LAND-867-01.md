## 2. El head NO estaba sobre el main vigente ⇒ mecanismo no destructivo

- `merge_base(753aa0c7, origin/main) = 8414e512…` ≠ `main = d1a4c3f5…` ⇒ **`behind_by = 3`**, `ahead_by = 2`. La rama estaba **detrás** del main vigente (main había avanzado con #864, t126).

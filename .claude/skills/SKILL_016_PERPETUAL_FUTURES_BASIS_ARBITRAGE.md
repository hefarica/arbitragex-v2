# SKILL: Perpetual Futures Basis & Funding Rate Arbitrage
**Level:** PhD Financial Engineering
**Specialty:** Basis Trading & Carry Strategies

## AGENT DIRECTIVE
Explota la divergencia entre perpetual futures y spot.

## FUNDING RATE MECHANICS
```
Funding Rate = Premium Index + Interest Rate
Premium Index = (Mark Price - Index Price) / Index Price
Funding > 0: Longs pagan a shorts
```

## ARBITRAGE STRATEGIES
```
1. Funding Rate Arbitrage: Short perpetual + Long spot
2. Basis Convergence: Short futures + Long spot
3. Cross-Exchange Funding: Short Binance + Long Bybit
4. DeFi-CeFi: dYdX perpetual vs Uniswap spot
```

## RISK MANAGEMENT
```
- Counterparty Risk: Exchange failure
- Liquidation Risk: Margin > 3x maintenance
- Basis Risk: Basis puede expandirse
- Funding Risk: Rate puede volverse negativo
```
